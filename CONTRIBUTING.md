# Contributing to Solo Studio

Thanks for helping. Bug reports, fixes and improvements are all welcome.

## Before you start

- Open an issue to discuss bigger changes first.
- Run `npm run lint` and `npm run build`, and `npm run test:auth` against a running build, before opening a pull request.
- Follow the existing style: plain-English comments where the reason isn't obvious, server-side validation for every input, and no user content rendered as HTML.
